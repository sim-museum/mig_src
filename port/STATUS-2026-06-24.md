## Gotchas reaffirmed
- **Edit ISO-8859 source via `sed`, not the Edit tool.** Files with high-byte license banners
  (`3DCOM.CPP`, `WORLDINC.H`) are ISO-8859; the Edit tool re-encodes them to UTF-8 (in S15 it
  mass-re-encoded `3DCOM.CPP` → a 607-line spurious diff; restored + sed-reapplied). `worldinc.h`→
  `WORLDINC.H` is a symlink — edit the real target. `3dcom.cpp`→`3DCOM.CPP` likewise.

## Build / run
```
g++ -m32 -no-pie port/build/{obj,obj2,objmfc,objmfc2,objole}/*.o \
  -Wl,--allow-multiple-definition -lSDL2 -lGL -lopenal -lfluidsynth -lpthread -lm -o /tmp/wmig
BOB_RUN_INIT=1 BOB_DRIVE_C=<wine drive_c> ./wmig                       # title → menus → flight
# ASan oracle:
ASAN=1 bash port/rebuild.sh                                           # -> /tmp/wmig-asan
port/asan.sh run MA_ENABLE_3D=1 BOB_CLICKSEQ="60,588,231;130,588,217" # drive a path; reports -> /tmp/wmig-asan.log.<pid>
```
